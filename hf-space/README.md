Hermes Agent (fork zema-tech/hermes-agent) running on a free CPU Space.

Secrets to set in Settings -> Variables and secrets:
`GROQ_API_KEY`, `DISCORD_BOT_TOKEN`, `DISCORD_ALLOWED_USERS`,
`HERMES_DASHBOARD_BASIC_AUTH_USERNAME`, `HERMES_DASHBOARD_BASIC_AUTH_PASSWORD`,
`HERMES_DASHBOARD_BASIC_AUTH_SECRET`.

Source: https://github.com/zema-tech/hermes-agent (see `hf-space/`).
